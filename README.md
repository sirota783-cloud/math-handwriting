# Интернет-сборщик рукописных символов — без ограничения

Ученик пишет столько символов, сколько хочет. После полного прохода по каталогу начинается новый круг. Завершение происходит только по кнопке «Завершить и отправить».

## Каталог

Иврит с конечными формами, латинские прописные и строчные, цифры, греческие буквы, арифметика, анализ, множества, логика, геометрия, стрелки, скобки и пунктуация.

## Проверка

Откройте `index.html`. Пока облачная база не подключена, программа в конце скачает JSON-файл на устройство.

## Подключение Supabase

1. Создайте проект Supabase.
2. Выполните `supabase_setup.sql` в SQL Editor.
3. Вставьте Project URL и anon public key в `config.js`.
4. Не вставляйте service_role key.

## Публикация

Распакованную папку можно опубликовать через Netlify Drop, GitHub Pages или Firebase Hosting.

## Что сохраняется

Анонимный код, правильный символ, категория, координаты и время штрихов, давление и наклон пера при наличии, тип ввода, PNG-изображение и технические размеры холста. Имена и контакты не собираются.

## Персональный профиль Леонида

Страница `leonid.html` собирает почерк Леонида отдельно от анонимных данных учащихся. Можно выбрать буквы иврита, математические символы или оба набора. По умолчанию предлагается 10 повторений каждого знака.

Персональные отправки получают код с префиксом `LEONID-`. В сохранённые данные также добавляются поля `datasetScope`, `profileId` и `profileSet`.
