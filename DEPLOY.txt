ГОТОВО ДЛЯ ПУБЛИКАЦИИ

1. Для проверки сайта можно открыть index.html.
2. Для публикации по одной ссылке загрузите содержимое этой папки на Netlify Drop / GitHub Pages / Firebase Hosting.
3. Чтобы ответы студентов автоматически собирались у преподавателя, сначала создайте проект Supabase:
   - выполните supabase_setup.sql в SQL Editor;
   - вставьте Project URL и anon/public key в config.js.
   ВАЖНО: service_role key сюда вставлять нельзя.
4. После изменения config.js опубликуйте папку целиком.

Без Supabase сайт работает, но при отправке скачивает JSON-файл на устройство студента вместо отправки преподавателю.
